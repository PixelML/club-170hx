**Question.** PR #90 got `thinkingmachines/Inkling-2-Mini` running on SM80 with six minimal compatibility patches (`108.56 tok/s` 6-prompt median / `146.0 tok/s` code on a stock CMP 170HX, `491.1 tok/s` at `c=16`, `432.5 s` cold startup, `32,768` context). How far can a stock-clocked CMP 170HX (`1,140 MHz` SM / `1,728 MHz` HBM2e, strict `140.00 W` TDP, `1,600.5 GB/s` D2D copy bandwidth) push single-user decode, `c=16` throughput, uncached short/long prefill, and full `262,144`-token context (including 13-group coalesced `806,085–809,126`-token `3.07–3.09x` FP8 KV) from one unified server without changing the target decode distribution (`100% 0-ULP`) and with `0` register spills across all kernels, and how does the same SM80 stack transfer to `A100` (`108` SMs)?

**Answer (measured): `108.56 → 134.98 → 155.48 → 164.25 → 167.24 → 171.84 → 173.78 → 175.37 → 176.61 tok/s` (`+62.7%`, beating bracketed Round-7 controls `ctl-57/58` by `+4.17` to `+4.29 tok/s` and `6/6` prompts simultaneously) single-user decode, `491.1 → 708.72 tok/s` BF16 (`+24.90 tok/s` over bracketed `ctl-58 = 683.82`; `718.77 tok/s` `+46.4%` all-time FP8 peak) `c=16` aggregate, and `4,999.2 / 3,894.7 tok/s` (`+22.0% / +8.7%` over Round 7, `+47.7%` over Round 6) `131K / 231K` long-context prefill on the same unified server at full `262,144` context (`0` register spills across `libsm80_r6_ext.so` and all `94` Humming `.cubin`s).** On PR #90's exact benchmark harness (`harness/bench.py`, 768 output tokens) at `262,144` context on the stock card, Round-8 Best reaches **`221.6 tok/s` code (`233.7` at `T=0`, `233.9` peak — all-time pooled code record), `195.3 tok/s` structured JSON (`232.6` peak, `+6.1 tok/s` over R7; `305.1 tok/s` JSON extraction on the agentic suite), `131.7 tok/s` prose (`133.7` peak), and `640.5 tok/s` at `c=16`**, scoring **GSM8K-50 `50/50 (100.0%)` BF16 / `49/50 (98.0%)` FP8**. Long-context needle retrieval hits **`3/3` at `131,227` tokens (`4,999.2 tok/s` prefill, TTFT `32.0 → 26.2 s` / `207.58 tok/s` decode) and `3/3` at `231,044` tokens (`3,894.7 tok/s` prefill, TTFT `64.5 → 59.3 s` / `161.32 tok/s` decode)**, cutting **`2 × 167.8K` concurrent soak wall time to `85.14 s` (`2/2` PASS)** and warm server startup to **`114.5–116.3 s`**. In 13-group coalesced **`--kv-cache-dtype=fp8` (`806,085–809,126` KV tokens = `3.07–3.09x` @ `262K`)**, Round 8 lifts short `c=1` decode to an all-time record **`170.57 tok/s` (`+40.2%` over R4 FP8, `+3.06 tok/s` over bracketed `ctl-59 = 167.51`)**, reaches **`699.33 tok/s` at `c=16` (`+10.03 tok/s` over `ctl-59`)**, lifts `231K` FP8 decode to **`159.21 tok/s` (`+4.2%` over R7, `3/3` needles)**, and passes **`4 × 172.0K` concurrent soak (`4/4` streams = `690,044` KV tokens in `414.3 s`, `12/12` needles)** + **GSM8K-50 `49/50 (98.0%)`**. Cross-validated on **NVIDIA A100-SXM4-40GB** (`sm_80`, `108` SMs, `131K` 13-group FP8 KV), the SM80 stack lifts `vllm serve` **`169.17 → 187.09 tok/s` (`+10.6%`) at `c=1`** and **`1,116.96 → 1,189.20 tok/s` (`+6.5%`) at `c=16`**.

## Winning stack summary

1. **Round-8 `100% 0-ULP`, `0`-spill 1-call C++ speculative rejection sampler, fused DSpark prologue & 0-spill Humming MoE (`patches/sm80_r6_ext.cu`, `patches/overlay/sm80_rejection.py`, `patches/overlay/humming_include/humming/{scheduler,epilogue/pipeline,epilogue/gmem_writer,arith/mainloop_arith}.cuh`, `patches/overlay/nvidia/{dspark.py,ops/dspark.py,ops/moe_sm90.py,ops/ll_gemm_sm80.py}`, `patches/overlay/speculator.py`, 0 spills):**
   - **1-call C++ rejection pipeline (`launch_sm80_rejection_sampler_r8`):** fuses `gather_draft_sampled` + temperature scaling + local max/sumexp + block/chain verification + Gumbel-max residual resampling + `get_num_sampled_and_rejected` with bit-exact 10-round Philox-4x32 + Murmur3 Gumbel + `-INFINITY` SFU skipping (`1,072 → 146 µs` at `c=1 T=0`, `1,074 → 159 µs` at `c=1 T=0.6`, `1,085 → 158 µs` at `c=16 T=0`, `1,074 → 286 µs` at `c=16 T=0.6`).
   - **Fused DSpark prologue & zero-allocation workspace:** fuses `prepare_context_anchor` (`f_rnn`) into `sm80_mix_rmsnorm_4x` (`-7` launches/step at `0-ULP`), wires `_k_norm_rope_write_kv_kernel` into `store_context_kv` (`-6` launches/step) + `B>=1` `_dspark_embed_block_kernel` (`-3` launches/step) + in-place `_store_hidden_states` (`torch.cat(..., out=...)`) + `_HUMMING_STATIC_WS`.
   - **Zero-spill Humming MoE tiles & streaming L2 hints (`94/94` cubins `STACK:0 LOCAL:0`):** `evict=True` on `c=1` MXFP8/NVFP4 MoE (`c1_step_ms = 14.9688 ms`), `stg=3 cta=2` on MXFP8 `c_m48_w13` (`-441.6 µs/step` at `c=16`), `stg=2` `[128, 256, 64] w=[64, 64, 64]` on `c_pf4k` (`REG:238/248 STACK:0`, `-21.6%` MoE prefill), `44 <= M <= 128` 5-way `_qkv_dyn_bmm_kernel`, and `0-ULP` `nw=4` `wo_ud` & `loc_qkvr`.
2. **Round-7 `100% 0-ULP` Humming SiTU epilogue, pass-hoisted/rank-2 loop bank, FlashInfer/Triton hybrid prefill, 5-way `qkv_dyn` & TP=2 support (`gmem_writer.cuh`, `sm80_r6_ext.cu`, `nvidia/loop.py`, `attention_sm90.py`, `sm80_tp_ops.py`):** fuses `gate_cap=4.0, up_cap=25.0` softcapped SwiGLU + routing `gamma` inside `GMemWriter` (`-48` launches/step, `3×` less intermediate HBM traffic), batches 48 core queries per pass (`-22` launches/step), decomposes `T >= 256` prefill bank attention via zero-spill CUDA MMA rank-2 kernels (`-44.0%` loop prefill), and routes `max_query_len >= 256` global prefill to zero-copy FlashInfer HND `FAR` + Triton `NEAR` (`-47.7%`) and local prefill to 3-interval unmasked Triton (`-32.8%`).
3. **Round-6 `100% 0-ULP` SM80 autoresearch CUDA & Triton kernels (`sm80_r6_ext.cu`, `nvidia/{loop.py,dspark.py}`, `speculator.py`, 0 spills):** 1-launch 48-CTA 3-K-group `select_and_align_mma256_k3g_t16` (`-96` launches/step), `combine_2304_r6` + `cp.async` `conv_mix_288_r6`, `sm80_up_blend_x_mma_2304` + `sm80_rms_norm_x_2304`, `_partials_workspace` (`-48` allocs/step) + `156 KiB` GA100 SMEM cap, and batched `c=16` `sm80_markov_sample_batch` (`-52.9%` DSpark `c=16` latency).
4. **Universal `0-ULP` 140 W Cold-HBM SM80 Humming MoE buckets (`moe_sm90.py`), standalone SM80 CUDA megakernels (`sm80_fast_v6.cu`), low-M Tensor-Core linears & FA2 vision (`ll_gemm_sm80.py`, `nvidia/{model.py,vision.py}`), lossless DSpark `K=49,152` pruning + `"block"` verification + dynamic batch `k`, monolithic `M <= 21` FULL CUDA graphs, 18-split decode attention, and 13-group coalesced SM80 E4M3 FP8 KV (`806,085–809,126` KV tok = `3.07–3.09x` @ `262K`).**
