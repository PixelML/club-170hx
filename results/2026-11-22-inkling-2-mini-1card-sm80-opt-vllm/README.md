**Question.** PR #90 got `thinkingmachines/Inkling-2-Mini` running on SM80 with six minimal compatibility patches (`108.56 tok/s` 6-prompt median / `146.0 tok/s` code on a stock CMP 170HX, `491.1 tok/s` at `c=16`, `432.5 s` cold startup, `32,768` context). How far can a stock-clocked CMP 170HX (`1,140 MHz` SM / `1,728 MHz` HBM2e, strict `140.00 W` TDP, `1,600.5 GB/s` D2D copy bandwidth) push single-user decode, `c=16` throughput, uncached short/long prefill, and full `262,144`-token context (including 13-group coalesced `805,704–809,126`-token `3.07–3.09x` FP8 KV) from one unified server without changing the target decode distribution (`100% 0-ULP`), and how does the same SM80 stack transfer to `A100` (`108` SMs)?

**Answer (measured): `108.56 → 134.98 → 155.48 → 164.25 → 167.24 → 171.84 → 173.78 → 175.37 tok/s` median / `175.52 tok/s` peak (`+61.5%` / `+61.7%`, beating all 4 bracketed Round-6 controls AND Round-6 Best on 6/6 prompts simultaneously) single-user decode, `491.1 → 718.77 tok/s` peak (`+46.4%`, `703.09–705.96 tok/s` BF16 / `718.77 tok/s` 13-group FP8) `c=16` aggregate, and `6,484.9 / 6,787.6 tok/s` (`6,506.0 / 6,788.0` peak, `+14.7%` at `32K` over Round 6) cold prefill on the same unified server at full `262,144` context.** On PR #90's exact benchmark harness (`harness/bench.py`, 768 output tokens) at `262,144` context on the stock card, Round-7 Best reaches **`220.4 tok/s` code (`234.9` at `T=0`, `235.3` peak), `189.2 tok/s` structured JSON (`226.5` peak; `241.9 tok/s` `T=0.6` mean and `308.3 tok/s` JSON extraction on the agentic suite), `132.7 tok/s` prose (`135.9` peak), and `657.4 tok/s` at `c=16`**, scoring **GSM8K-50 `49/50 (98.0%)`** (`50/50` in Round 6). Long-context needle retrieval jumps to **`3/3` at `131,227` tokens (`4,098.9 tok/s` prefill `+12.0%` vs R6 / `216.41 tok/s` decode) and `3/3` at `231,044` tokens (`3,584.3 tok/s` prefill `+36.0%` vs R6, TTFT `87.6 → 64.5 s` / `169.38 tok/s` decode `+5.5%` vs R6 — all-time `231K` records)**, cutting **`2 × 167.8K` concurrent soak wall time `113.3 → 87.6 s` (`-22.7%`, `2/2` PASS)** and server startup to **`110.3–112.3 s`**. In 13-group coalesced **`--kv-cache-dtype=fp8` (`805,704–809,126` KV tokens = `3.07–3.09x` @ `262K`)**, Round 7 lifts short `c=1` decode **`121.62 → 162.59 → 167.66 → 169.56 tok/s` (`169.71` peak, `+39.5%` over R4 FP8, beating R6 FP8 on `6/6` prompts simultaneously)**, sets the all-time **`c=16` record at `718.77 tok/s` (`+46.4%`)**, lifts `131K / 231K` FP8 decode to **`204.32 / 152.80 tok/s` (`3/3` needles)**, and passes **`4 × 172.0K` concurrent soak (`4/4` streams = `689,932` KV tokens in `409.6 s`, `12/12` needles)** + **GSM8K-50 `48/50 (96.0%)`**. Cross-validated on **NVIDIA A100-SXM4-40GB** (`sm_80`, `108` SMs, `131K` 13-group FP8 KV), the SM80 stack lifts `vllm serve` **`169.17 → 187.09 tok/s` (`+10.6%`) at `c=1`** and **`1,116.96 → 1,189.20 tok/s` (`+6.5%`) at `c=16`**.

## Winning stack summary

1. **Round-7 `100% 0-ULP` Humming SiTU epilogue, pass-hoisted/rank-2 loop bank, FlashInfer/Triton hybrid prefill, 5-way `qkv_dyn` & TP=2 support (`patches/overlay/humming_include/humming/epilogue/gmem_writer.cuh`, `patches/sm80_r6_ext.cu`, `patches/overlay/nvidia/{loop.py,attention.py}`, `patches/overlay/nvidia/ops/{attention_sm90.py,moe_sm90.py,ll_gemm_sm80.py,conv_mix.py}`, `patches/overlay/sm80_tp_ops.py`, 0 spills):**
   - **Fused softcapped SwiGLU + routing `gamma` inside Humming's `w13` epilogue (`0-ULP`):** fuses `gate_cap=4.0, up_cap=25.0` softcapped SwiGLU and routing weight multiplication directly in `GMemWriter` before writing `[N_slots, 1152]` BF16, deleting 48 `swiglu_1152` launches/step and cutting `w13 → w2` intermediate HBM traffic `3×` via a content-SHA256 `Compiler.cuh_last_update_time` hook.
   - **Pass-hoisted 48-query decode bank (`0-ULP`) + zero-spill CUDA MMA rank-2 prefill bank (`-44.0%` loop prefill):** batches all 48 core queries per pass (`-22` launches/step at `0-ULP`) and decomposes `T >= 256` prefill bank attention via `sm80_bank_stats_r7`, split-BF16 `torch.mm`, `sm80_bank_rank2_finalize_r7`, `sm80_pair_rms_norm_rank2_bcast3_r7`, and `MT=4` double-buffered `sm80_up_blend_rank2_mma_2304_r7` (saving `~450 MB` peak prefill VRAM), paired with `T > 64` `combine_2304_pf_r7` + `prefill_conv_mix_288_r7` (`-62.4%` `combine_conv` prefill) and `BM=32/128` prefill MoE buckets (`-20.5%` MoE prefill) while keeping `[8, 256, 128]` on `(256, 912]` for `718.77 tok/s` `c=16`.
   - **Zero-copy FlashInfer HND `FAR` + Triton `NEAR` hybrid global prefill (`-47.7%`), 3-interval unmasked local prefill (`-32.8%`), `0-ULP` `FAR` decode loop (`-6.7%`), 5-way single-loop `_qkv_dyn_bmm_kernel` (`-28.6%`, `-16` launches/step), and `_C::vocab_parallel_embedding` TP=2 stand-in:** drives `32K` prefill `+14.7%` (`6,788.0 tok/s`) and `231K` prefill **`+36.0%` (`3,584.3 tok/s`)** while keeping decode and short prompts (`max_query_len < 256`) `100% 0-ULP`.
2. **Round-6 `100% 0-ULP` SM80 autoresearch CUDA & Triton kernels (`patches/sm80_r6_ext.cu`, `patches/overlay/nvidia/{loop.py,dspark.py}`, `patches/overlay/speculator.py`, 0 spills):** 1-launch 48-CTA (`BN=8 × 3` exact K-groups `1024, 1024, 256`) double-buffered MMA `select_and_align_mma256_k3g_t16` (`-96` launches/step), `combine_2304_r6` + `cp.async` power-of-2 `conv_mix_288_r6`, `sm80_up_blend_x_mma_2304` + `sm80_rms_norm_x_2304`, preallocated `_partials_workspace` (`-48` allocs/step) + `156 KiB` GA100 SMEM cap in `ll_gemm_sm80.py`, and `0-ULP` `sm80_mix_rmsnorm_4x` + 4-warp `_qk_norm_rope_write_kv_kernel` + `_dspark_embed_block_kernel` + batched `c=16` `sm80_markov_sample_batch` (`-52.9%` DSpark `c=16` latency on CMP 170HX, `-49.3%` on A100).
3. **Universal `0-ULP` (`torch.equal == True`) 140 W Cold-HBM SM80 Humming v5 MoE buckets (`patches/overlay/nvidia/ops/moe_sm90.py`):** 8-warp `num_warps_k=1` `[8, 128, 64] w=[8, 32, 64] stg=5 cta=3 evict=False` on `NVFP4 w13 (16, 256]` (`-0.461 ms/step`), `[8, 256, 128] w=[8, 64, 64] stg=4 cta=2 evict=True` on `NVFP4 w13 (256, 912]`, `[8, 128, 128] w=[8, 64, 64] stg=3 cta=3 evict=True` on `NVFP4 w2 (16, 256]`, `stg=4 cta=3` `[8, 128, 64]` on `MXFP8 w2` (`1.553 → 0.863 ms`), `BM=32/96/128` prefill buckets above `2,048` rows, and dynamic `num_compute_units()` scaling across 74-SM CMP 170HX and 108-SM A100.
