**Question.** PR #90 got `thinkingmachines/Inkling-2-Mini` running on SM80 with six minimal compatibility patches (`108.56 tok/s` 6-prompt median / `146.0 tok/s` code on a stock CMP 170HX, `491.1 tok/s` at `c=16`, `432.5 s` cold startup, `32,768` context). How far can a stock-clocked CMP 170HX (`1,140 MHz` SM / `1,728 MHz` HBM2e, strict `140.00 W` TDP, `1,600.5 GB/s` D2D copy bandwidth) push single-user decode, `c=16` throughput, and full `262,144`-token context (including 13-group coalesced `809,126`-token `3.09x` FP8 KV) from one unified server without changing the target output distribution (`100% 0-ULP`), and how does the same SM80 stack transfer to `A100` (`108` SMs)?

**Answer (measured): `108.56 → 134.98 → 155.48 → 164.25 → 167.24 → 171.84 → 173.78 tok/s` median (`+60.1%`, beating all 5 bracketed Round-5 controls on 6/6 prompts simultaneously) single-user decode and `491.1 → 710.92 tok/s` median / `716.68 tok/s` peak (`+44.8%` / `+45.9%`, beating control on 16/16 streams) `c=16` aggregate on the same unified server at full `262,144` context.** On PR #90's exact benchmark harness (`harness/bench.py`, 768 output tokens) at `262,144` context on the stock card, Round-6 Best reaches **`217.4 tok/s` code (`231.5` at `T=0`), `202.4 tok/s` structured JSON (`219.7` `T=1` median, `229.2` peak; `301.9–313.0 tok/s` on agentic JSON extraction), `130.8 tok/s` prose (`134.2` peak), and `667.3 tok/s` at `c=16`**, scoring **GSM8K-50 `50/50 (100%)`**. Long-context needle retrieval is **`3/3` at `131,227` tokens (`3,658.8 tok/s` prefill / `219.16 tok/s` decode) and `231,044` tokens (`2,636.2 tok/s` prefill / `160.57 tok/s` decode)**, and in 13-group coalesced **`--kv-cache-dtype=fp8` (`809,126` KV tokens = `3.09x` @ `262K`)**, Round 6 jumps short `c=1` decode **`121.62 → 162.59 → 167.66 tok/s` (`+37.9%` over R4 FP8, `252.28 tok/s` code peak)**, lifts `c=16` to **`713.24 tok/s` (`715.17` peak)**, cuts startup to **`109.7–114.4 s`**, lifts `231K` FP8 decode **`141.55 → 150.78 tok/s` (`3/3` needles)**, and passes **`4 × 172.0K` concurrent soak (`4/4` streams, `12/12` needles)** + **GSM8K-50**. Cross-validated on **NVIDIA A100-SXM4-40GB** (`sm_80`, `108` SMs, `131K` 13-group FP8 KV), Round 6 lifts end-to-end `vllm serve` **`169.17 → 187.09 tok/s` (`+10.6%`) at `c=1`** and **`1,116.96 → 1,189.20 tok/s` (`+6.5%`) at `c=16`**.

## Winning stack summary

1. **Round-6 `100% 0-ULP` SM80 autoresearch CUDA & Triton kernels (`patches/sm80_r6_ext.cu`, `patches/overlay/nvidia/{loop.py,dspark.py}`, `patches/overlay/speculator.py`, 0 spills):** 1-launch 48-CTA (`BN=8 × 3` exact K-groups `1024, 1024, 256`) double-buffered MMA `select_and_align_mma256_k3g_t16` (`-96` launches/step), `combine_2304_r6` + `cp.async` power-of-2 `conv_mix_288_r6` (`0-ULP` fused `combine_conv_mix_2304`), `0-ULP` `sm80_up_blend_x_mma_2304` + `sm80_rms_norm_x_2304`, 1-pass `0-ULP` Triton `_bank_attn_res_1pass_kernel` (`2–4×` fewer bank HBM reads), preallocated `_partials_workspace` (`-48` allocs/step) + `156 KiB` GA100 SMEM cap in `ll_gemm_sm80.py`, and `0-ULP` `sm80_mix_rmsnorm_4x` + 4-warp `_qk_norm_rope_write_kv_kernel` + `_dspark_embed_block_kernel` + batched `c=16` `sm80_markov_sample_batch` (`-52.9%` DSpark `c=16` latency on CMP 170HX, `-49.3%` on A100).
2. **Universal `0-ULP` (`torch.equal == True`) 140 W Cold-HBM SM80 Humming v5 MoE buckets (`patches/overlay/nvidia/ops/moe_sm90.py`):** 8-warp `num_warps_k=1` `[8, 128, 64] w=[8, 32, 64] stg=5 cta=3 evict=False` on `NVFP4 w13 (16, 256]` (`-0.461 ms/step`), `[8, 256, 128] w=[8, 64, 64] stg=4 cta=2 evict=True` on `NVFP4 w13 (256, 912]`, `[8, 128, 128] w=[8, 64, 64] stg=3 cta=3 evict=True` on `NVFP4 w2 (16, 256]`, `stg=4 cta=3` `[8, 128, 64]` on `MXFP8 w2` (`1.553 → 0.863 ms`), `BM=96` prefill buckets above `2,048` rows, and dynamic `num_compute_units()` scaling across 74-SM CMP 170HX and 108-SM A100.
3. **Custom SM80 CUDA megakernels (`patches/sm80_fast_v6.cu`, `patches/overlay/sm80_ops_v2.py`, 0 spills) + low-M Tensor-Core linears & FA2 vision (`ll_gemm_sm80.py`, `nvidia/{model.py,vision.py}`):** `moe_align_v3_sm80`, `swiglu_1152_sm80`, `pair/blend_rms_norm_2304_sm80`, `markov_rnn_gate_256_sm80`, `markov_fold_gumbel_cache_r1_sm80`, `BN=128` `8600×2304` `loc_qkvr`, 1-launch `_qkv_bmm_kernel`, batched `MP=64` `loop.blend`, `cuBLAS` `M>=5` `lm_head`, and SM80 FA2 ViT vision.
4. **Lossless DSpark `K=49,152` pruning + zero-scatter `-inf` `DraftLogitsCache` + bidirectional `k=4` + joint block verification (`"block"`) + dynamic batch `k` (`[[1,2,4],[3,6,3],[7,256,2]]`).**
5. **Monolithic `M <= 21` FULL CUDA graphs + slots-safe Sconv metadata deduplication + 18-split SM80 global decode attention + 13-group coalesced SM80 E4M3 FP8 KV (`809,126` KV tok = `3.09x` @ `262K`, `167.66 tok/s` `c=1`, `713.24 tok/s` `c=16`, `109.7 s` boot).**
